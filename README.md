# Birthday Reminder Pro 🎂

A modern Windows birthday reminder app built with Python and CustomTkinter.

## Features

- 🎂 Birthday dashboard with search and upcoming birthdays
- 👤 Person profiles with photos
- 🔔 Automatic background notification at Windows login/restart without opening the main GUI
- 👥 Multiple birthdays on the same date
- 📅 Advance reminder for birthdays falling on Sunday, 2nd Saturday, or 4th Saturday
- 🗑️ Delete birthday/contact entries
- 💬 WhatsApp greeting launcher
- ✍️ Five greeting styles with sender name at the end
- 💾 Local JSON storage under `%USERPROFILE%\\BirthdayReminder`

## Build on Windows

Run `BUILD_EXE.bat`. The resulting executable is `dist\\Birthday Reminder Pro.exe`.

Run the EXE once to install the background Windows Startup launcher. Birthday data and photos stay on the local PC and are not part of this repository.
